## 📦 まず用語を整理する

AI駆動開発のツール群は、大きく **3つのレイヤー** に分けて考えると理解しやすいです。

### ① モデル（頭脳）

ChatGPT・Claude・Geminiなどの **大規模言語モデル（LLM）** です。コードを書いたり、日本語で説明したりする「頭脳」の部分。

**OpenCode Go** は、この「モデル」を月額固定で使い放題にするサービスです。DeepSeek・Qwen・GLMなど、オープンソース系の高性能モデルをAPI経由で呼び出せます。

### ② コーディングCLI（手と足）

モデルという「頭脳」に、**実際にファイルを作ったり編集したりする「手と足」** を与えたものがコーディングCLIツールです。

| コーディングCLI | 開発元 | バックエンドのモデル |
|---|---|---|
| **Claude Code** | Anthropic | Claude のみ |
| **OpenCode** | OpenCode | 任意（OpenCode Go, OpenRouter, etc.） |
| **Codex CLI** | OpenAI | GPT のみ |

つまり **OpenCode は Claude Code と同等の役割** を持つツールです。どちらも「ターミナル上で動くAIプログラマー」であり、ファイルの読み書き・git操作・デバッグを自律的に実行します。

### ③ エージェントフレームワーク（司令塔）

コーディングCLIの上位レイヤーとして、**複数のモデルを切り替えたり、並列タスクを管理したり** する枠組みです。

**Hermes Agent** はこの層にあたり、OpenCode（や他のCLI）を経由してモデルを呼び出しつつ、**スキル保存・記憶・子エージェント並列実行・cronジョブ** などの高度な機能を提供します。

整理すると：

```
[Hermes Agent]  ← 司令塔（スキル・記憶・並列実行）
    └─ [OpenCode]  ← 手と足（ファイル操作・git・デバッグ）
         └─ [OpenCode Go]  ← 頭脳（DeepSeek/Qwenなどのモデル）
```

## 🚪 Claude Codeをやめた理由

Claudeは推論性能が高く、日本語も非常に自然です。**Claude Codeも間違いなく優秀なツール** でした。

しかし、最初の壁は **Rate Limit（使用制限）** でした。

Claude Pro（$20/月）では、5時間ごとの制限に加えて週間の上限があり、集中して開発していると**数時間で「今日はもう使えません」と言われる** ストレスがありました。日本円で月約¥3,200を払ってこの制限は、正直割に合わないと感じました。

---

## 🖥️ ローカルLLMにも手を出した

「自前のPCでモデルを動かせば無料で使い放題では？」

そう考え、Ollama（CLI）と LM Studio（GUI）で **Qwen3 8B / Qwen3-Coder 30B MoE** をローカル実行してみました。環境は M1 Pro MacBook Pro（32GB RAM）です。

結果：**最初の応答に1分以上かかる**。

企業の大規模GPUクラスタと違い、個人のマシンでは推論速度がまったく実用的ではありませんでした。アイデアを素早く形にしたいコーディング用途では、この遅延は致命的です。

## 🎯 なぜ OpenCode Go + OpenCode + Hermes Agent なのか

2026年現在、**オープンソースモデルの性能は Claude Opus 4.7 や GPT-5.5 に肉薄** しています。Kimi・GLM・DeepSeek・Qwen・MiniMaxなど、かつて「安かろう悪かろう」だったモデル群が、最先端と遜色ない水準に達しているのです。

そして **OpenCode Go（月$10）** は、それら高性能モデルを **使い放題で提供する** サブスクリプションです。

### OpenCode Go（モデル提供サービス）

- 月$10（初月$5）の固定料金
- 使った分だけ課金される従量制**ではない**
- Rate Limitは**実質気にならないレベル**
- APIキーを発行し、好きなツールから呼び出す形で使う
- 対応モデルは増え続けている（2026年5月時点でDeepSeek, Qwen, GLM, MiniMaxなど）

https://opencode.ai/ja/go

### OpenCode（コーディングCLI）

Claude CodeやCodexのようなコーディングCLIです。
Claude Codeより直感的な操作感です。バックエンドのモデルを自由に切り替えられる点が最大の違い。

https://opencode.ai/ja

### Hermes Agent（エージェントフレームワーク）

ターミナル上で動くAIエージェントで、**モデルを自由に選べる** のが最大の特徴です。OpenCode GoのAPIキーを設定すれば、DeepSeek系モデルをバックエンドに使えます。

主な機能：

- **スキルシステム**：よく使うワークフローを保存・呼び出し
- **子エージェント並列実行**：複数タスクを同時に処理
- **記憶（メモリ）**：セッションを跨いで設定や好みを保持
- **cronジョブ**：定期実行タスクのスケジュール
- **スラッシュコマンド**：`/plan` `/review` など定型操作を即実行

https://hermes-agent.nousresearch.com
